# Oele51 Hausverein app

A simple residents' app for Oele51: reservations for rooms and tables, laundry slots per floor, events and an info board.

- Plan: [docs/PLAN.md](docs/PLAN.md)
- Clickable prototype: [prototype/index.html](prototype/index.html)

The prototype file is written as a page fragment (no `<html>` or `<body>` tags) and keeps example data in the browser only. It has no server and no real login yet.
